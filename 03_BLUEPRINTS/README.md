# AWS-Onion — LEGO Blueprints

Patrones de montaje reutilizables. Cada blueprint tiene **requisito**, verbos y puertos, diagramas separados de data/control plane, exclusiones (piezas innecesarias), disponibilidad, seguridad y coste.

Primeros blueprints en [[AWS-Onion - LEGO Architecture Map]]: web regional escalable; alta disponibilidad multi-region; VPC pública/privada.

> Un blueprint NO es una receta única: ajustar según carga, estado, RTO/RPO, costos y políticas.
