# AWS-Onion — Glossary

| Term | Mental association |
|---|---|
| VPC | Private AWS network boundary |
| Subnet | Portion of VPC CIDR where resources live |
| Route Table | Path / road signs |
| IGW | Internet doorway for the VPC |
| NACL | Stateless subnet-level filter |
| Security Group | Stateful resource/ENI-level filter |
| ENI | Virtual NIC — connects and identifies |
| ENA | Enhanced networking — accelerates |
| EFA | Low-latency fabric for tightly coupled clusters |
| EC2 | Virtual computer |
| User Data | Instructions at launch |
| Metadata | Instance learns about itself |
| Group | Same User identity; permissions through membership |
| Role | Assumable identity used through a Role session |
| STS | Issues temporary security credentials |
| SSM Agent | Software in the machine that communicates with Systems Manager |
| Session Manager | Administration without direct inbound SSH |
| CloudWatch | Metrics/monitoring/instrument panel |

This glossary should grow with each certification lesson.
