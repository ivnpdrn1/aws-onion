# Certification Roadmap

## Purpose

AWS-Onion will grow alongside three certification tracks while maintaining one connected mental model.

## Solutions Architect

Focus areas include VPC, CIDR, subnets, routing, Internet connectivity, NACLs, Security Groups, ENIs, EC2, placement groups, load balancing, scaling, storage, databases, IAM, high availability, resilience and monitoring.

## Developer

Focus areas will include IAM roles and temporary credentials, AWS CLI/SDK, Lambda, API Gateway, EventBridge, SNS/SQS, DynamoDB, Step Functions, CloudWatch, Systems Manager, CI/CD and application configuration.

## AI

Focus areas will include AWS AI services, Amazon Bedrock, agents/orchestration, embeddings/vector search, responsible AI, security/IAM for AI workloads, data paths, monitoring and cost control.

## Rule for every new topic

Every service or concept added to AWS-Onion should answer:

```text
What problem does it solve?
        ↓
Where is it in the Onion?
        ↓
What does it depend on?
        ↓
What does it provide?
        ↓
Who/what needs IAM permission?
        ↓
What network path is required?
        ↓
What should I associate with it on the exam?
```

The goal is progressive understanding rather than isolated memorization.
